# From Hitter to Player

Project page for **From Hitter to Player: Separating Motor Execution and
Strategy in Competitive Humanoid Table Tennis**.

This repository contains the static project website, paper PDF, figures,
self-hosted fonts and icons, and silent demonstration videos.

Open `index.html` for a local preview. GitHub Pages publishes the `main`
branch from the repository root. The `.nojekyll` file enables direct static
publication.

All published video files have their audio tracks removed. Original video
uploads, training code, paper source files, and unpublished drafts are not
included in this website repository.

The 11:4 match uses `match-411-youhua.mp4`, a complete 85.1-second 720p
recording. It replaces the previous `match-411.mp4` file and poster.
